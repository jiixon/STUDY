## 경로표현식

- .(점)을 찍어 객체 그래프를 탐색


> 💡 <br>
> select m.username -> 상태 필드 <br>
> from Member m <br>
> join m.team t -> 단일 값 연관 필드 <br>
> join m.orders o -> 컬렉션 값 연관 필드 <br>
> where t.name = '팀A'



- 상태 필드 : 단순히 값을 저장하기 위한 필드
    - 경로 탐색의 끝, 탐색X
    - `select m.username from Member m`
- 연관 필드 : 연관관계를 위한 필드
    - 단일 값 연관 필드
        - @ManyToOne, @OneToOne → 대상이 엔티티
        - **묵시적 내부 조인(inner join) 발생**, 탐색O
        - `select m.team from Member m`

      ![경로표현식](/JPA/images/img19.png)

    - 컬렉션 값 연관 필드
        - @OneToMany, @ManyToMany → 대상이 컬렉션
        - **묵시적 내부 조인 발생**, 탐색X
        - `select t.members from Team`
        - 여기서 t.members.username → 탐색 불가능
        - FROM 절에서 명시적 조인을 통해 별칭을 얻으면 별칭을 통해 탐색 가능
            - 해결법 : `select m.username from Team t join t.members m`

### 상태 필드 경로 탐색

JPQL, SQL 동일

- JPQL : `select m.username, m.age from Member m`
- SQL : `select m.username, m.age from Member m`

### 단일 값 연관 경로 탐색

- JPQL : `select **o.member** from Order o`
- SQL : `select m.* from Orders o **inner join Member m on o.member_id = m.id**`

### 명시적 조인, 묵시적 조인

- 명시적 조인 : join 키워드 직접 사용

  select m from Member m join m.team t

- 묵시적 조인 : 경로 표현식에 의해 묵시적으로 SQL 조인 발생 (내부 조인)

  select m.team from Member m


### 주의사항

- 경로 탐색을 위한 묵시적 조인 → 항상 내부 조인
- 컬렉션은 경로 탐색의 끝 → 명시적 조인을 통해 별칭 얻어야 함
- 경로 탐색은 주로 SELECT, WHERE 절에서 사용하지만, 묵시적 조인으로 인해 SQL의 FROM(JOIN) 절에 영향을 줌
- 가급적으로 묵시적 조건이 아닌 명시적 조인 사용
