### 영속상태

1. `em.persist()`
2. `em.find()` → 1차 캐시에 없음 → DB 조회 → 1차 캐시 저장

→ 위 두가지가 영속성 컨텍스트에 올라감 == 영속 상태

### 준영속 상태

- 영속 상태의 엔티티가 영속성 컨텍스트에서 분리(detached)
- 영속성 컨텍스트가 제공하는 기능을 사용 못함
- 예시

    ```java
    //영속
    Member member = em.find(Member.class, 150L);
    Mmember.setName("newName");
    
    //준영속
    em.detach(member);
    
    tx.commit();
    ```

    - `setName()` 데이터 변경은 `commit` 시점에서 더티체킹으로 update 쿼리 나가는게 정상
    - 하지만, `em.detach(member);`
        - 영속 상태 → 준영속 상태
        - 더이상 영속성 컨텍스트에 존재하지 않고, JPA가 관리 하지 않는 상태
    - `commit()` 시점에 아무일도 일어나지 않음(udpate 쿼리X)

### 준영속 상태로 만드는 방법

- `em.detach(entity)`
    - 특정 엔티티만 준영속 상태로 전환
- `em.clear()`
    - 영속성 컨텍스트를 완전히 초기화
- `em.close()`
    - 영속성 컨텍스트를 종료
